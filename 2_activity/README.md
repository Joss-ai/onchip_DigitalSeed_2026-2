# FIFO Design for FoM Optimization

This activity presents a **FIFO (First-In, First-Out) design** developed with the objective of improving the **FOM**.

The Verilog source files are located in the `src/` directory, while the configuration file required for the RTL-to-GDSII flow is located in the `GDS/` directory. The design is intended to be processed using **open-source EDA tools**, specifically the **JKU IIC-OSIC Tools container**.

This activity is part of **DigitalSeed**, a initiative of the **OnChip research group**.

## Directory Structure

```text
├── src/
│   └── Verilog source files
├── GDS/
│   └── Configuration file
└── README.md
```
