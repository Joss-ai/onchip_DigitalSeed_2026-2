TX por dentro

El bloque con sus 16 entradas y 5 salidas y, dentro, sus cuatro piezas: (a) TSR, (b) contador de ticks, (c) contador de bits y (d) FSM. Los nombres coinciden con uart_tx_ctrl.sv. Pulsa +1 tick y mira cómo se mueven todas juntas mientras se envía la letra.

Las cajas de borde punteado (foto de configuración y lógica de salida) son piezas pequeñas de apoyo; el trabajo principal lo hacen (a), (b), (c) y (d). Las líneas internas se encienden en naranja cuando están actuando en ese tick.

a

TSR · registro de desplazamiento

  • Guarda el carácter que se está enviando (8 casillas).
  • La casilla de la derecha, tsr[0], es la que sale por el cable.
  • Se carga cuando la FSM toma el carácter del FIFO (tx_pop).
  • Se desplaza a la derecha al terminar cada bit de datos; por la izquierda entra un 1.
always_ff @(posedge clk)
  if (rst || !utrst)
    TSR <= 8'hFF;
  else if (CARGA)
    TSR <= tx_data;
  else if (DESPLAZA)
    TSR <= {1'b1, TSR[7:1]};
b

Contador de ticks

  • Suma 1 con cada pulso bclk_tick.
  • Cuando llega al último valor (15 con 16×, 12 con 13×) y llega otro tick, avisa “fin de bit” y vuelve a 0.
  • En STOP el último valor puede ser mayor (23 ó 31) si hay 1.5 ó 2 bits de stop.
  • Es lo que garantiza que cada bit dure exactamente lo mismo.
assign FIN_BIT = bclk_tick &&
  (CUENTA_TICK == ((presente == STOP) ? FIN_STOP_N : FIN_BIT_N));

always_ff @(posedge clk)
  if (rst || !utrst || CARGA)
    CUENTA_TICK <= 6'd0;
  else if (bclk_tick && presente != IDLE)
    CUENTA_TICK <= FIN_BIT ? 6'd0 : CUENTA_TICK + 6'd1;
c

Contador de bits

  • Solo trabaja en el estado DATA: dice qué bit de datos está saliendo.
  • Suma 1 cada vez que termina un bit de datos.
  • Se compara con el último bit (4, 5, 6 ó 7 según wls). Si ya es el último, la FSM pasa a PARITY o STOP.
  • Fuera de DATA vale 0.
assign ULTIMO   = (CUENTA_BIT == ULTIMO_BIT);
assign DESPLAZA = (presente == DATOS) && FIN_BIT;

always_ff @(posedge clk)
  if (rst || !utrst || CARGA)
    CUENTA_BIT <= 3'd0;
  else if (DESPLAZA)
    CUENTA_BIT <= ULTIMO ? 3'd0 : CUENTA_BIT + 3'd1;
d

FSM · máquina de estados

  • Es el “cerebro”: decide en qué parte de la trama vamos.
  • Avanza de estado solo cuando (b) dice “fin de bit”.
  • En DATA pregunta a (c) si ya salió el último bit.
  • Da las órdenes a (a): cargar o desplazar. Y genera tx_pop, tsr_empty y tx_busy.
always_ff @(posedge clk)
  if (rst || !utrst) presente <= IDLE;
  else               presente <= futuro;

always_comb
  case (presente)
    IDLE:    futuro = (bclk_tick && HAY_DATO) ? START : IDLE;
    START:   futuro = FIN_BIT ? DATOS : START;
    DATOS:   if (FIN_BIT && ULTIMO)
               futuro = CON_PARIDAD ? PARIDAD : STOP;
             else futuro = DATOS;
    PARIDAD: futuro = FIN_BIT ? STOP : PARIDAD;
    STOP:    if (FIN_BIT && HAY_DATO) futuro = START;
             else if (FIN_BIT)        futuro = IDLE;
             else                     futuro = STOP;
    default: futuro = IDLE;
  endcase

Lo que va saliendo por el cable (txd)

Cada bloque de color es un bit (16 ticks). Rojo = start, azul = datos, morado = paridad, verde = stop, gris = reposo.
