Le dice al simulador la unidad de tiempo y define la caja: cómo se llama el módulo y cuáles son sus 16 entradas y 5 salidas.

  • `timescale 1ns / 1psUnidad de tiempo para simular: los retardos se miden en nanosegundos, con precisión de picosegundos. No afecta al circuito.
  • module uart_tx_ctrl (El nombre del módulo. Tus compañeros lo usarán con este nombre para conectarlo.
  • input logic ...Las 16 entradas. logic es el tipo de SystemVerilog que sirve para todo (reemplaza a reg y wire). [7:0] significa 8 bits; [1:0], 2 bits.
  • output logic ...Las 5 salidas: txd (el cable), tx_pop, tsr_empty, tx_serial_loop y tx_busy.

¿Por qué tx_data tiene [7:0]? Porque la letra entra completa, los 8 bits a la vez (en paralelo).

Registros internos y foto de configuración

a · b · c líneas 27–35
 27    logic [7:0] TSR;
 28    logic [5:0] CUENTA_TICK;
 29    logic [2:0] CUENTA_BIT;
 30  
 31    logic [2:0] ULTIMO_BIT;
 32    logic       CON_PARIDAD;
 33    logic       BIT_PARIDAD;
 34    logic [5:0] FIN_BIT_N;
 35    logic [5:0] FIN_STOP_N;

Declara las memorias internas: las tres piezas principales y la “foto” donde se guarda la configuración de la letra que se está enviando.

  • TSR [7:0](a) El registro de desplazamiento: guarda la letra que está saliendo.
  • CUENTA_TICK [5:0](b) Cuenta los ticks dentro de cada bit. 6 bits porque debe llegar hasta 31 (el stop de 2 bits).
  • CUENTA_BIT [2:0](c) Dice qué bit de datos va saliendo (0 a 7). 3 bits alcanzan para contar hasta 7.
  • ULTIMO_BIT, CON_PARIDAD, BIT_PARIDAD, FIN_BIT_N, FIN_STOP_NLa foto: cuántos bits tiene la letra, si lleva paridad, cuál es el bit de paridad y cuántos ticks dura un bit y el stop. Se copian una sola vez, al tomar la letra.

¿Por qué guardar una foto y no usar wls, pen, etc. directamente? Porque la CPU podría cambiar la configuración a mitad del envío y la letra saldría dañada.

Declara las señales que conectan las piezas entre sí. Son los “avisos” que se pasan unas a otras.

  • CTS_A, CTS_BLos dos flip-flops del sincronizador de CTS.
  • FIN_BIT(b) avisa: “este bit ya duró lo que tenía que durar”.
  • ULTIMO(c) avisa: “este es el último bit de datos”.
  • HAY_DATOHay una letra en la fila y CTS deja enviar.

  • MASCARA, PARIDAD_CALCAyudan a calcular la paridad.
  • SEL, OCUPADO, LINEASalidas de la FSM: qué poner en el cable, si está ocupado, y el valor final de la línea.

Aquí solo se declaran; lo que hace cada una se define más abajo con assign o always.

Crea un tipo nuevo llamado estado_t con los 5 estados y dos variables de ese tipo: el estado presente y el futuro.

  • typedef enum logic [2:0]Un enum le pone nombre a cada número. Con 3 bits caben hasta 8 estados; usamos 5.
  • IDLE = 000 … STOP = 100Reposo, start, datos, paridad y stop, cada uno con su código binario.

Ventaja del enum: en las ondas de GTKWave se ven los nombres (IDLE, START…) en vez de 0, 1, 2…

FSM

La máquina de estados

d · FSM segmentos 04–07

La FSM es el “cerebro” del módulo: decide en qué parte de la letra vamos. Tiene 5 estados. Cada flecha lleva la condición exacta del código y, en naranja, lo que pasa al tomarla. Las flechas curvas indican que el estado se queda igual mientras no se cumpla ninguna condición de salida.

Reset: desde cualquier estado, si rst = 1 o utrst = 0, la FSM vuelve a IDLE en el siguiente flanco de reloj (segmento 05).

IDLE 3'b000

Reposo. “Idle” en inglés significa “inactivo” u “ocioso”. Es el estado en el que el transmisor no está enviando nada y espera a que haya una letra en la fila. Es el estado inicial y al que vuelve tras un reset.

05

Registro de estado

d · FSM líneas 60–64
 60    always_ff @(posedge clk)
 61      if (rst || !utrst)
 62        presente <= IDLE;
 63      else
 64        presente <= futuro;

En cada flanco de reloj, la FSM pasa al estado futuro. Si hay reset (o el TX está apagado), vuelve a reposo.

  • always_ff @(posedge clk)Bloque de flip-flops: se ejecuta en cada flanco de subida del reloj.
  • if (rst || !utrst) presente <= IDLE;Reset general o utrst = 0 → a reposo.
  • else presente <= futuro;Si no, avanza al estado que calculó la lógica de estado futuro.

Se usa <= (no bloqueante) porque es un registro: todos los flip-flops cambian a la vez en el flanco.

 93          if (FIN_BIT && HAY_DATO)

Decide a qué estado ir según el estado actual y los avisos FIN_BIT, ULTIMO y HAY_DATO. Es el “cerebro” del módulo.

  • IDLESi llega un tick y hay dato → START. Si no, se queda en IDLE.
  • STARTCuando termina el bit (FIN_BIT) → DATOS.
  • DATOSCuando termina el último bit → PARIDAD si hay paridad, si no → STOP. Mientras no sea el último, se queda en DATOS (el TSR se va desplazando).
  • PARIDADCuando termina el bit → STOP.
  • STOPAl terminar: si hay otra letra → START directo (sin pausa); si no → IDLE.
  • defaultPor seguridad: si por algún motivo el estado fuera inválido, vuelve a IDLE.

always_comb usa = (bloqueante) porque es lógica combinacional: no guarda nada, solo calcula.

Según el estado, elige qué va en el cable (SEL) y si el transmisor está ocupado (OCUPADO).

  • SEL = 00 en STARTEl cable va a 0 (el bit de start).
  • SEL = 01 en DATOSEl cable toma el bit TSR[0].
  • SEL = 10 en PARIDADEl cable toma el bit de paridad.
  • SEL = 11 en IDLE y STOPEl cable va a 1.
  • OCUPADO0 solo en IDLE; 1 en todos los demás estados (está enviando).

Es una FSM tipo Moore: estas salidas dependen solo del estado presente.

08

Sincronizador de CTS

control líneas 134–141
134    always_ff @(posedge clk)
135      if (rst) begin
136        CTS_A <= 1'b1;
137        CTS_B <= 1'b1;
138      end else begin
139        CTS_A <= cts_n;
140        CTS_B <= CTS_A;
141      end

cts_n viene de un pin externo que no va al ritmo del reloj. Pasa por dos flip-flops en fila para “limpiarla” antes de usarla.

  • CTS_A <= cts_n;Primer flip-flop: puede quedar un instante inestable (metaestabilidad).
  • CTS_B <= CTS_A;Segundo flip-flop: ya sale una señal estable. El resto del módulo usa CTS_B.
  • reset → 1Tras un reset arranca en 1 (“esperar”) por seguridad.

Costo: CTS se ve con 2 ciclos de retraso, que no importa frente a los cientos de ciclos que dura un bit.

09

Condiciones de control

control líneas 143–148
143    assign HAY_DATO = !tx_empty && !(afe && CTS_B);
144    assign FIN_BIT  = bclk_tick && (CUENTA_TICK == ((presente == STOP) ? FIN_STOP_N : FIN_BIT_N));
145    assign ULTIMO   = (CUENTA_BIT == ULTIMO_BIT);
146    assign CARGA    = !rst && utrst && bclk_tick && HAY_DATO &&
147                      ((presente == IDLE) || (presente == STOP && FIN_BIT));
148    assign DESPLAZA = (presente == DATOS) && FIN_BIT;

Cinco ecuaciones que generan los avisos y órdenes que usan la FSM y las piezas.

  • HAY_DATOLa fila no está vacía y no es cierto que (afe esté activo y CTS diga esperar).
  • FIN_BITLlegó un tick y el contador ya está en el último valor (el de stop si estamos en STOP, el normal si no).
  • ULTIMOEl contador de bits es igual al último bit guardado en la foto.
  • CARGANo hay reset, el TX está encendido, hay tick, hay dato, y el TSR está libre (en IDLE o justo terminando el stop). También sale como tx_pop.
  • DESPLAZAEstamos en DATOS y terminó un bit.

CARGA depende del estado y además de entradas (tick, dato): por eso va en un assign y no en el case de salidas.

10

Cálculo de paridad

paridad líneas 150–151
150    assign MASCARA      = 8'hFF >> (2'd3 - wls);
151    assign PARIDAD_CALC = ^(tx_data & MASCARA);

Cuenta si la letra tiene un número par o impar de unos, usando solo los bits que realmente se envían.

  • MASCARA = 8'hFF >> (3 - wls)Deja en 1 solo los bits usados: 5 bits → 0001_1111, 8 bits → 1111_1111.
  • PARIDAD_CALC = ^(tx_data & MASCARA)El operador ^ delante hace XOR de todos los bits: da 1 si hay un número impar de unos y 0 si es par.

Para la “A” (0100_0001) hay dos unos → PARIDAD_CALC = 0.

11

(a) TSR: registro de desplazamiento

a · TSR líneas 153–159
153    always_ff @(posedge clk)
154      if (rst || !utrst)
155        TSR <= 8'hFF;
156      else if (CARGA)
157        TSR <= tx_data;
158      else if (DESPLAZA)
159        TSR <= {1'b1, TSR[7:1]};

Guarda la letra y la va corriendo hacia la derecha, un bit por cada bit de datos que sale.

  • reset → 8'hFFTras un reset queda lleno de unos.
  • CARGA → TSR <= tx_dataCopia la letra que viene del FIFO.
  • DESPLAZA → {1'b1, TSR[7:1]}Corre todo una posición a la derecha y mete un 1 por la izquierda. El bit que estaba en TSR[1] pasa a TSR[0], que es el que sale por el cable.

Por eso sale primero el bit menos significativo: siempre se envía TSR[0].

(b) Contador de ticks

b · ticks líneas 161–165
161    always_ff @(posedge clk)
162      if (rst || !utrst || CARGA)
163        CUENTA_TICK <= 6'd0;
164      else if (bclk_tick && presente != IDLE)
165        CUENTA_TICK <= FIN_BIT ? 6'd0 : CUENTA_TICK + 6'd1;

Cuenta los pulsos bclk_tick para que cada bit dure exactamente 16 (o 13) ticks.

  • reset o CARGA → 0Empieza desde 0 al tomar una letra nueva.
  • tick y no IDLE → +1Con cada tick suma 1…
  • FIN_BIT → 0…y cuando llega al final del bit vuelve a 0 para el siguiente.

En IDLE no cuenta: no hay bit que medir.

(c) Contador de bits

Foto de configuración

config líneas 173–188
173    always_ff @(posedge clk)
174      if (rst || !utrst) begin
175        ULTIMO_BIT  <= 3'd7;
176        CON_PARIDAD <= 1'b0;
177        BIT_PARIDAD <= 1'b1;
178        FIN_BIT_N   <= 6'd15;
179        FIN_STOP_N  <= 6'd15;
180      end else if (CARGA) begin
181        ULTIMO_BIT  <= {1'b1, wls};
182        CON_PARIDAD <= pen;
183        BIT_PARIDAD <= sp ? ~eps : (eps ? PARIDAD_CALC : ~PARIDAD_CALC);
184        FIN_BIT_N   <= osm_sel ? 6'd12 : 6'd15;
185        FIN_STOP_N  <= !stb           ? (osm_sel ? 6'd12 : 6'd15)
186                     : (wls == 2'b00) ? (osm_sel ? 6'd18 : 6'd23)
187                     :                  (osm_sel ? 6'd25 : 6'd31);
188      end

En el momento de CARGA copia la configuración del LCR. Esa copia se usa hasta terminar la letra.

  • ULTIMO_BIT <= {1'b1, wls}Es 4 + wls: 5 bits → último es D4; 8 bits → D7.
  • CON_PARIDAD <= penSi esta letra lleva paridad.
  • BIT_PARIDADSi sp = 1: paridad fija (eps=0 → 1, eps=1 → 0). Si no: par → PARIDAD_CALC; impar → su negado.
  • FIN_BIT_N15 con 16× (cuenta 0..15 = 16 ticks) o 12 con 13×.
  • FIN_STOP_N1 stop → 15/12; 1.5 stop → 23/18; 2 stop → 31/25.

Se cuenta desde 0, por eso 16 ticks terminan en 15.

Salida: qué va al cable

salida líneas 190–203
190    always_comb begin
191      case (SEL)
192        2'b00:   LINEA = 1'b0;
193        2'b01:   LINEA = TSR[0];
194        2'b10:   LINEA = BIT_PARIDAD;
195        default: LINEA = 1'b1;
196      endcase
197    end
198  
199    assign tx_serial_loop = LINEA & ~bc;
200    assign txd            = loop ? 1'b1 : tx_serial_loop;
201    assign tx_pop         = CARGA;
202    assign tsr_empty      = !OCUPADO;
203    assign tx_busy        = OCUPADO;

Convierte SEL en el valor de la línea y aplica break y loopback. Al final conecta las salidas del módulo.

  • case (SEL) → LINEA00 → 0, 01 → TSR[0], 10 → bit de paridad, 11 → 1.
  • tx_serial_loop = LINEA & ~bcSi bc = 1 (break), fuerza 0.
  • txd = loop ? 1 : tx_serial_loopEn loopback el pin se queda en 1 y la señal solo va al receptor.
  • tx_pop = CARGAAvisa al FIFO que ya tomó la letra.
  • tsr_empty = !OCUPADO, tx_busy = OCUPADOEstado del transmisor para el LSR y la emulación.

txd es la salida más importante: es el cable por donde sale la letra.

Recorrido completo con la “A”

Así se usan los segmentos, en orden, al enviar la “A” (8 bits, paridad par, 1 stop):

  1. En reposo, presente = IDLE y el cable está en 1 →07 →15.
  2. Llega un tick y hay letra: HAY_DATO = 1 y CARGA = 1 →09; eso es tx_pop.
  3. En ese flanco el TSR se carga con 0100_0001 →11, se toma la foto con paridad 0 →10 →14 y la FSM pasa a START →06.
  4. START: SEL = 00, el cable va a 0 durante 16 ticks →12.
  5. DATOS: sale TSR[0]; con cada FIN_BIT se activa DESPLAZA, el TSR se corre y CUENTA_BIT sube →11 →13. Salen 1 0 0 0 0 0 1 0.
  6. Con ULTIMO = 1 y CON_PARIDAD = 1 pasa a PARIDAD: sale el 0 guardado →06.
  7. STOP: el cable va a 1 durante 16 ticks. La fila está vacía, así que vuelve a IDLE y tsr_empty = 1 →15.

 90            futuro = PARIDAD;
 91  
 92        STOP:
 93          if (FIN_BIT && HAY_DATO)
 94            futuro = START;
 95          else if (FIN_BIT)
 96            futuro = IDLE;
 97          else
 98            futuro = STOP;
 99  
100        default:
101          futuro = IDLE;
102      endcase
103    end
104  
105    always_comb begin
106      case (presente)
107        IDLE: begin
108          SEL     = 2'b11;
109          OCUPADO = 1'b0;
110        end
111        START: begin
112          SEL     = 2'b00;
113          OCUPADO = 1'b1;
114        end
115        DATOS: begin
116          SEL     = 2'b01;
117          OCUPADO = 1'b1;
118        end
119        PARIDAD: begin
120          SEL     = 2'b10;
121          OCUPADO = 1'b1;
122        end
123        STOP: begin
124          SEL     = 2'b11;
125          OCUPADO = 1'b1;
126        end
127        default: begin
128          SEL     = 2'b11;
129          OCUPADO = 1'b0;
130        end
131      endcase
132    end
133  
134    always_ff @(posedge clk)
135      if (rst) begin
136        CTS_A <= 1'b1;
137        CTS_B <= 1'b1;
138      end else begin
139        CTS_A <= cts_n;
140        CTS_B <= CTS_A;
141      end
142  
143    assign HAY_DATO = !tx_empty && !(afe && CTS_B);
144    assign FIN_BIT  = bclk_tick && (CUENTA_TICK == ((presente == STOP) ? FIN_STOP_N : FIN_BIT_N));
145    assign ULTIMO   = (CUENTA_BIT == ULTIMO_BIT);
146    assign CARGA    = !rst && utrst && bclk_tick && HAY_DATO &&
147                      ((presente == IDLE) || (presente == STOP && FIN_BIT));
148    assign DESPLAZA = (presente == DATOS) && FIN_BIT;
149  
150    assign MASCARA      = 8'hFF >> (2'd3 - wls);
151    assign PARIDAD_CALC = ^(tx_data & MASCARA);
152  
153    always_ff @(posedge clk)
154      if (rst || !utrst)
155        TSR <= 8'hFF;
156      else if (CARGA)
157        TSR <= tx_data;
158      else if (DESPLAZA)
159        TSR <= {1'b1, TSR[7:1]};
160  
161    always_ff @(posedge clk)
162      if (rst || !utrst || CARGA)
163        CUENTA_TICK <= 6'd0;
164      else if (bclk_tick && presente != IDLE)
165        CUENTA_TICK <= FIN_BIT ? 6'd0 : CUENTA_TICK + 6'd1;
166  
167    always_ff @(posedge clk)
168      if (rst || !utrst || CARGA)
169        CUENTA_BIT <= 3'd0;
170      else if (DESPLAZA)
171        CUENTA_BIT <= ULTIMO ? 3'd0 : CUENTA_BIT + 3'd1;
172  
173    always_ff @(posedge clk)
174      if (rst || !utrst) begin
175        ULTIMO_BIT  <= 3'd7;
176        CON_PARIDAD <= 1'b0;
177        BIT_PARIDAD <= 1'b1;
178        FIN_BIT_N   <= 6'd15;
179        FIN_STOP_N  <= 6'd15;
180      end else if (CARGA) begin
181        ULTIMO_BIT  <= {1'b1, wls};
182        CON_PARIDAD <= pen;
183        BIT_PARIDAD <= sp ? ~eps : (eps ? PARIDAD_CALC : ~PARIDAD_CALC);
184        FIN_BIT_N   <= osm_sel ? 6'd12 : 6'd15;
185        FIN_STOP_N  <= !stb           ? (osm_sel ? 6'd12 : 6'd15)
186                     : (wls == 2'b00) ? (osm_sel ? 6'd18 : 6'd23)
187                     :                  (osm_sel ? 6'd25 : 6'd31);
188      end
189  
190    always_comb begin
191      case (SEL)
192        2'b00:   LINEA = 1'b0;
193        2'b01:   LINEA = TSR[0];
194        2'b10:   LINEA = BIT_PARIDAD;
195        default: LINEA = 1'b1;
196      endcase
197    end
198  
199    assign tx_serial_loop = LINEA & ~bc;
200    assign txd            = loop ? 1'b1 : tx_serial_loop;
201    assign tx_pop         = CARGA;
202    assign tsr_empty      = !OCUPADO;
203    assign tx_busy        = OCUPADO;
